# Contributing

Open an issue with reproducible steps, Chrome version, extension version, and redacted error text. Do not attach real OAuth tokens, credentials, private documents, or student information.

For changes, run `npm run check` and `npm test`, reload the unpacked extension, and manually test the affected workflow. Keep AI requests restricted to loopback and render model-produced content as text. Document any new permissions or outbound data flows in PRIVACY.md.

The owner has not selected an open-source license yet; resolve licensing before contributing code for redistribution.
